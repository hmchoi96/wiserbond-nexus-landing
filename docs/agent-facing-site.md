# Product-first, agent-facing public site

The site serves two audiences: a person signs up and authorizes a connection;
an agent needs readable discovery, exact capabilities, limits and execution evidence.
The product working name remains Akashic until a new name and domain are selected.
The legal operator remains Wiserbond Technologies Inc.

The public agent guide, llms.txt and product-specific JSON document share the
runtime tool names inspected in akashic-v2/main's surface.py on 2026-11-11. The
existing setup manifest is linked for per-host status instead of claiming every
host has identical or guaranteed autonomous behavior. Runtime tools/list and current
account policy remain authoritative. Discovery files help readers find and assess
the service; they do not guarantee that a crawler or agent will choose it.

Trust signals are inspectable data: source, author, time, state, revision, ambiguity,
policy scope and a real receipt.request_id. Reviewed memory is not independent
verification of its underlying claim. No fictional customer proof or competitor
performance comparison is used. The homepage interaction is explicitly an example,
not a simulated authenticated session.

V1 content and research remain available in the archive. New metadata and generated
Open Graph images describe the current product rather than the archived PE product.
The site origin is configurable; no domain purchase or DNS change is part of this
revision. Only public service information belongs in agent-facing documents.
